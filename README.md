# 守門員大作戰（網頁版）

用兩支健身趣（智能握力環 Fit 100，藍牙名稱 `FUNFITGRIP`）當左右手撲球：握右手往右撲、握左手往左撲。

**開始玩：** https://ianpy91g.github.io/keeper-game/

## 玩法

| 健身趣 | 觸控 | 鍵盤 | 動作 |
|---|---|---|---|
| 握右手 | 點右半邊 | → | 往右撲 |
| 握左手 | 點左半邊 | ← | 往左撲 |
| 兩手一起握（0.25 秒內） | 兩邊同時點 | ↑／空白鍵 | 使出大招「重影」 |

- 共 10 關，每關 10 球、3 顆心，被踢進一球扣一顆，心用完挑戰失敗（可從這一關重來）。
- 每一球只能撲一次，撲了就不能換邊。
- 球飛到球門的時間：第 1 關 1.5 秒，每關快 0.09 秒，第 10 關約 0.7 秒。
- **變化球**：第 6 關起出現，球先往一邊飛，飛到一半轉向另一邊（後面會拖一條黃色弧線）；越後面越常出現。太早撲會被騙。
- **大招「重影」**：連續撲到 10 球存一次（最多 3 次），被踢進就歸零。使出時左右各出現一個分身，這一球不管左右、雙球、變化球都擋得住。
- **雙球**：第 3 關起，手上有大招時才會出現，左右同時射門，就是使出重影的時機。
- 其他畫面（選單、關卡說明、過關、失敗）：握一下＝下一步。
- 記錄最高分與最遠關卡；背景音樂可在選單右上角開關（鍵盤 M）。

## 連線

- 選單按「連接左手」「連接右手」，各選一支 `FUNFITGRIP`。左右手會記住，下次打開自動重連（瀏覽器支援時）。
- 握力環要在 **BLE 模式**（開機鍵雙擊會切到 HID 模式，要再雙擊切回）。
- 電腦上的 `kiwi_keys.py`／`ring_keys.py` 要先停掉（`停止握力環.bat`），否則握力環被電腦佔住，平板找不到。

| 裝置 | 瀏覽器 |
|---|---|
| iPad / iPhone | **Bluefy**（Safari 不支援網頁藍牙），iOS 12 以上 |
| Android | Chrome |
| 電腦 | Chrome / Edge |

## 協定（健身趣）

服務 `FFF0`：每 0.2 秒寫入 `FFF2` 一個位元組 `05`（查詢狀態），握力環才會持續回報；從 `FFF1` 收到 `0c 01`＝握下、`0c 00`＝放開。剛連線時第一次握下可能漏掉，所以 `04`／`0b` 狀態訊息的次數（第 5 個位元組）增加也算握下。

## 檔案

- `keeper.js`：遊戲本體（畫圖、邏輯、音效、音樂），不碰 DOM，可在 Node 測試
- `app.js`：畫面縮放、觸控、鍵盤、Web Bluetooth（兩支握力環）、存檔（localStorage）
- `index.html`：小外殼，每次以時間參數載入 keeper.js、app.js，避免 Bluefy 拿到快取的舊版
- 發佈新版時記得改 `keeper.js` 的 `VERSION`，畫面右下角會顯示
